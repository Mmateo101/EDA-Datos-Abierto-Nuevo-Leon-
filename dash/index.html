02 · Áreas temáticas

Grupos

Las bases de datos se organizan por grupo temático. Selecciona uno para ver su cumplimiento de actualización y sus bases de datos.

Cómo se calcula el score

Cada base de datos suma puntos por cumplir 5 criterios de calidad; el score de un grupo es el promedio del score de sus bases de datos.

CriterioPuntosQué se evalúa
Tiene diccionario de variables20El campo Diccionario (Si/No) está marcado como "Sí"
Tiene etiquetas20La base de datos tiene al menos una etiqueta asignada
Tiene grupo o categoría20La base de datos tiene al menos un grupo asignado
Descripción completa20Su descripción tiene más de 5 palabras
Vigente20Su próxima actualización esperada aún no ha pasado, según su periodicidad declarada

Score total = suma de los 5 criterios, de 0 a 100 puntos.

04 · Esquemas compartidos

Mapa de variables

Cada nodo es una base de datos; dos bases se conectan cuando usan variables con el mismo nombre en su diccionario (p. ej. ambas tienen una columna municipio). El grosor de la línea indica cuántos nombres de variable comparten.

Score ≥ 80 Score 50–79 Score < 50 Tamaño del nodo = número de variables en su diccionario · grosor de línea = variables compartidas
